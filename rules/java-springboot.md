# Java Spring Boot Guidelines

## Stack

- Java 21, Spring Boot 3.x
- Spring Data JPA with `ddl-auto: validate`
- Flyway for schema migrations (never `ddl-auto=update` in shared configs)
- Bean Validation on request DTOs

## Package Structure

```text
com.speckit.tickets/
├── controller/     # REST endpoints only
├── service/        # Business logic
├── domain/         # JPA entities and enums
├── repository/     # Spring Data repositories
├── dto/            # Request/response models
├── exception/      # @RestControllerAdvice handlers
└── config/         # CORS, security, etc.
```

## Conventions

- Use constructor injection (`@RequiredArgsConstructor`)
- Keep controllers thin; no business logic in controllers
- Return structured error responses with field-level validation details
- Enforce domain rules (e.g. state machine) in the service layer
- Use `@Transactional` on service methods that write data
- Set `spring.jpa.open-in-view: false`

## Database

- H2 file store for local dev; PostgreSQL for production (`application-prod.yml`)
- All schema changes via Flyway migrations in `db/migration/`
- Use `BIGINT GENERATED BY DEFAULT AS IDENTITY` for cross-database compatibility

## Key Design Decisions

1. **Separate status endpoint** — `PATCH /status` enforces state machine independently of field updates
2. **Local entities** — JPA models and repositories live in this repo only
3. **Cross-DB migration syntax** — `GENERATED BY DEFAULT AS IDENTITY` for H2 + PostgreSQL
4. **UI shows only valid transitions** — prevents blind reliance on backend 409 errors
